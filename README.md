This project was to create and test specific MergeSort candidates for effiency, reliability, and the memory usage for specific provided datasets.
● Analyzed, benchmarked, and debugged 3 candidate algorithms, authoring a detailed technical efficiency report to guide optimization 
strategies 
● Developed custom implementation for MergeSort algorithm to dynamically store data using a linked list allocated on the heap 
● Utilized Valgrind to test my implementation alongside other program candidates to profile memory usage/leaks, time and space 
complexity
